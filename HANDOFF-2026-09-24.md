## GOTCHAS WORTH KNOWING

- **Disposition notes have two voices.** "Revokes: EO 14036" means this order
  revoked that one — it says nothing about this order's own status. Only
  passive forms ("Revoked by:", "Amended by:", "Superseded by:") change a
  status. Reading it the other way marked all 24 revoking orders as revoked
  and left the one genuinely revoked order active; 42 rows were corrected on
  2026-09-22.
- **Commas are not separators in filter values.** Three industries contain
  one ("Aerospace, Defense & Government Services"); splitting on commas made
  them match nothing and show 0 results.
- **`federal_register_url` is NOT the govinfo PDF**, despite what the README
  used to say. It is the API's `html_url`. The real PDF is not stored.
- **`hasAdminAccess()` returns true when `SITE_PASSWORD` is unset** so local
  dev works. Never use it to authorize destructive actions — use
  `hasActiveAdminSession()`, which requires the gate to be configured *and*
  satisfied.
- **`content_drafts` is reached only via the service-role client.** Its RLS
  was written for Phase 5 accounts and no anonymous caller satisfies it.
- **Watchdog alerts go to a separate Slack account (JCHLQ)**, not Jason's
  main workspace. Connecting his main Slack does not show them — ask the
  endpoint instead (command below).
- Live ids are UUIDs; legacy JSON ids are `legacy-eo-N`. They never match.
- `document_number` is UNIQUE.
- Practice-area and subject tags are AI-generated with **no ground truth**.
